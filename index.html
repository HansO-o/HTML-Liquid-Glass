How it works

浏览器怎么支持，就怎么画

原生滤镜 · Chromium

backdrop-filter 加 SVG 位移图，按斯涅尔折射和超椭圆边缘生成。浏览器实时折射页面，iframe、视频、动画都是真的。

快照 + WebGL · Safari / Firefox

只有边缘那一圈从页面快照折射，中间仍是实时页面。拖动、滚动不重拍，拍不到的区域自动挖空。

只有一个 WebGL 上下文

所有玻璃共用一个 WebGL 上下文画高光和投影，玻璃再多也不会碰到浏览器的上下文数量限制。

跟手

每帧的测量和绘制排在页面自己的动画之后；在 Safari 的跨域 iframe 里动画被降到 30 fps 时，改由手指的移动来驱动。

Get started

加一个属性就是玻璃

<!-- 一个文件，零依赖 -->
<script src="liquid-glass.js"></script>

<nav data-liquid-glass="regular">…</nav>
<button data-liquid-glass="dark; button: true">播放</button>
<div data-liquid-glass="frosted; draggable: true">…</div>

// 也可以用 JS
const glass = LiquidGlass.create(el, { preset: 'regular', dim: 0.15 });
glass.set({ bezel: 0.1 });
